# 🌐 Internship Portal (Frontend Only)

## 📄 Project Description

The *Internship Portal* is a fully responsive frontend web application that provides students with an interface to:

- Apply for internships
- Generate offer letters
- Verify certificates
- Join internship teams
- Contact coordinators

> 💡 This is a frontend-only project using *HTML, **CSS, and **JavaScript*. No backend/database integration is included.
